Privacy Policy

Overview

Wan Shi Tong is a trivia application for Discord that allows users to test their knowledge by responding to a series of questions related to a user-provided topic. The bot's source code is available at: https://github.com/atlacord/trivia-bot.

Data Collection

We collect basic usage data for analysis purposes. This includes the following:

  • Guild ID
  • Trivia topics
  • Trivia session scores
We do not collect or store any user data.

If you have any questions or concerns, please email kyle@soda.gg, or visit the Avatar server at https://discord.gg/avatar and contact the admin team via modmail.
